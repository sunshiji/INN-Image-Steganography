## 核心源代码片段（代表性展示）

### 1. Logistic混沌加密核心

function: _logistic_sequence
logic: 使用参数r生成混沌序列
input: r(参数), x0(初值), n0(预热), length(长度)
output: 浮点序列数组
lines: ~10

function: _scramble
logic: 根据混沌序列排列进行像素重排
input: 平面像素数组, 排列指标
output: 重排后的像素
lines: ~3

function: _diffuse
logic: XOR像素与混沌密钥
input: 像素字节, 密钥序列
output: 加密后的像素
lines: ~3

### 2. INN可逆神经网络核心

class: CouplingBlock
architecture: 分割、残差、拼接
forward: (x1,x2) → (y1=x1, y2=x2+F(x1))
inverse: (y1,y2) → (x1=y1, x2=y2-F(y1))
lines: ~20

class: INNSteganography
encode: concat(cover,secret) → DWT → blocks → IDWT → (stego,noise)
decode: concat(stego,z) → DWT → blocks(reverse) → IDWT → secret
lines: ~50

### 3. HiNet隐写模型核心

class: INV_block
affine_coupling: 3个子网络(r,y,f)
clamp_exp: e^(clamp*2*(sigmoid(s)-0.5))
forward: y2 = e^(s1)*x2 + t1
inverse: y2 = (x2-t1)/e^(s1)
lines: ~30

class: HiNetSteganography
encode: DWT(cover,secret) → 16xINV_block → IWT → (stego,z)
decode: DWT(stego,z) → 16xINV_block(reverse) → IWT → secret
lines: ~40

### 4. Flask REST API核心

route: POST /api/encrypt
input: image (multipart/form-data)
logic: 加载→参数获取→加密→输出
output: encrypted_image, key, metrics (JSON)
lines: ~25

route: POST /api/encode
input: cover, secret (multipart/form-data)
logic: 验证→加载→编码→指标计算→DB记录
output: stego_image, stego_key, metrics (JSON)
lines: ~60

route: POST /api/decode
input: stego (multipart/form-data), stego_key? (optional)
logic: 加载→解码→输出→DB记录
output: secret_image, mode (exact/approximate)
lines: ~40

### 5. 数据库持久化核心

schema: users, stego_images, encode_tasks, decode_tasks

table: encode_tasks
cols: id, task_token, username, cover/secret/stego/recovery_id, 
      psnr, ssim, model_type, created_at, expires_at
operations: 记录任务、查询历史、自动过期清理
lines: ~50

## 编译/运行说明

运行环境:
  - Python 3.8+
  - Node.js 14+ (前端开发)
  - GPU可选（CUDA 10.2+推荐）

后端启动:
  cd backend
  pip install -r requirements.txt
  gunicorn -c gunicorn.conf.py app:app
  # 或开发模式
  python app.py  # http://localhost:5000

前端开发:
  cd frontend_v2
  npm install
  npm run dev
  # 生产构建
  npm run build
