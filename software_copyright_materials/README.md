## 核心功能

1. **Logistic混沌加密**
   - 像素级加密
   - 信息熵：≈8.0（加密后）
   - NPCR：≈99.6%
   - UACI：≈33.5%

2. **INN隐写编码**
   - Haar小波变换
   - 8层耦合块架构
   - PSNR：20-30 dB
   - SSIM：0.8-0.95

3. **HiNet隐写模型**
   - 16层可逆神经网络
   - 支持自定义权重加载
   - 性能更优

4. **多用户系统**
   - Flask + SQLite数据库
   - 用户认证与权限管理
   - 任务历史记录

## 技术亮点

✅ **双重加密隐写**

## 申报指南

### 提交方式
1. **标准交存**（推荐）
   - 源程序：前30页 + 后30页
   - 文档：前30页 + 后30页（如超过60页）
   - 每页至少30行代码

2. **例外交存**（可选）
   - 源程序前后各连续30页，机密部分用黑线覆盖
   - 覆盖部分≤50%
   - 或前10页+任意50页+目标程序30页

### 所需文件
✓ 源程序鉴别材料.docx （60页）  
✓ 使用说明书.docx （20+页）
